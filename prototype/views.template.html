What only the grid shows

  1. The EINTR column is a duplicate of its neighbour. Every pair of cells differing only in eintr_safe is identical — same accepts, same peak fds, same zombies. Python 3.5+ retries interrupted syscalls automatically (PEP 475), so the article's webserver3f.py fix is dead code on any modern Python. The article does not know this.
  2. wait() and waitpid(WNOHANG) are indistinguishable here. Both reaped all 40 children. The article's lesson — that wait() misses zombies because signals don't queue — needs a heavier load than 40 connections to appear. Load is a missing switch.
  3. Half the grid is one cell wearing twelve hats. With fork off, the other three switches do nothing at all. The space isn't a flat grid — which switches matter depends on the others.
