You’ve followed the whole chain
Share the work. Finish the cleanup.
  1. One busy process leaves later requests waiting.
  2. A child process handles each connection while the parent accepts more.
  3. Each process closes the socket references it no longer needs.
  4. The parent collects every finished child’s exit record.
Concurrency solves the wait. Socket ownership and child cleanup let the server keep doing it.
