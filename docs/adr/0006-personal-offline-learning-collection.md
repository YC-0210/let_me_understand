# Start with a personal, offline learning collection

The first application lets one learner revisit existing Visualizations and browse the animation library in a standalone Mac app, keeping learning history locally. The user chose this scope over multiple learner profiles and immediate source-to-Visualization generation, so accounts, synchronization, and generation are deferred rather than prerequisites for using existing lessons. This sets the first release’s product boundary without selecting a native framework or storage format.

The user directs authoring through the existing Codex app. The learning record does not adapt teaching in this release. In Q15 the user replaced the earlier assessment-based plan with a simple per-Concept checkbox and no additional judgment; scored prediction/scenario checks are therefore out of scope. Existing reader-controlled explanations and manual backup export/import remain in scope.
