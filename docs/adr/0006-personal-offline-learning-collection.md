# Start with a personal, offline learning collection

The first application will let one learner revisit existing Visualizations and browse the animation library in a standalone Mac app, keeping learning history locally. The user chose this scope over multiple learner profiles and immediate source-to-Visualization generation, so accounts, synchronization, and generation are deferred rather than prerequisites for using existing lessons. Learning checks supply understanding evidence; completing a lesson alone does not. This sets the first release’s product boundary without selecting a native framework or storage format.
