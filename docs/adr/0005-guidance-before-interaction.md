# Guidance before interaction

The user requires that readers can enter without reading the Source. Essential
context therefore stays visible above the drawing: the situation, the current change,
its consequence, and a concrete next action. Caption doors retain optional depth.
This clarifies Visual language §5; doors must not hide the main explanation.

Part 3 keeps one drawing per idea. Multiple clients and child processes occupy
separate horizontal lanes (an exception to §4's single axis), because a single lane
would conflate independent connections. Parent–child ancestry uses labelled dashed
history lines, never request channels. Descriptor references use labelled lines with
no travelling message. A process's place persists as a location after exit; its state
is named “exited” or “collected,” rather than suggesting it still runs. Wink is the
existing guide UI from Part 2, outside the system's mark grammar.

Manual steps show completed states. Optional playback advances the same named steps,
stopping at each chapter boundary; it never loops one event as if it happened again.
Reduced motion disables transitions but preserves manual steps and timed reading.
