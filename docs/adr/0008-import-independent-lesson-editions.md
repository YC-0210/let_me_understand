# Import independent lesson editions from Codex

The user chose importable lesson packages over directly loading the Codex project folder. The Mac app keeps an offline copy so a project move or later source edit cannot break or silently change a saved Visualization version. Authoring stays in Codex; explicit imports add editions, with separate reuse approval and shared Understanding marks only for unchanged Concepts. This adds a packaging/import step in return for a stable personal collection independent of the development checkout.
