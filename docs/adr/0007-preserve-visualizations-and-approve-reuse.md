# Preserve lesson versions and require approval for example reuse

The user chose to retain earlier Visualization versions and explicitly update saved lessons rather than let animation-library changes silently rewrite them. New Visualizations are ineligible as Reusable examples until the user approves them; excluding an example keeps it available for revisiting. This separates the learner’s historical material from the examples allowed to influence future generation, at the cost of keeping versions and approval decisions rather than one mutable latest lesson.
