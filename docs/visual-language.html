The Marks

Every drawing in this project is built from seven marks and three colours. A new mark or a new hue needs a written decision, not a judgement call in the moment.

Grammar

The marks combine under rules, the way words do.

  1. A disc never exists without a line to travel on.
  2. An arrowhead never exists alone — always on a disc or a line.
  3. A ring only surrounds a circle. Work is done by places, never by messages.
  4. A cross replaces a disc. They never appear together.
  5. A circle persists for the whole scene. A disc exists only while travelling.
  6. Text names marks. Text never explains inside the drawing.

BREAKS RULE 3

A message cannot work. It only travels.

Colour

Three roles. Everything that persists and does not move is grey.

Structure Places and channels. Never coloured.#8a8f98 · #34343a
The reader's action Whatever they caused — the request they sent.#5e6ad2
Outcome: present A thing came back.#27a644
Outcome: absent Nothing came back. Always with the cross.#d95448
  1. Colour never decorates. Remove a colour; if nothing becomes unknowable, it should not have been there.
  2. Grey is the default. A mark earns colour by carrying data.
  3. Status is never colour alone. Absence always carries the cross. Measured: green against red separates by ΔE 0.9 under deuteranopia — indistinguishable. Accent against green separates by 26.5.
  4. One accent, forever. Emphasis is size, surface lift or motion — never a second hue.
  5. Any new hue passes the validator first, in both modes: validate_palette.js "<hex,…>" --mode dark
  6. Text takes text colours, except a value that is the datum.

Motion

Duration is meaning. The longest beat belongs to the step the reader cannot otherwise see.

Line openseased 450ms
Request travelseased 1100ms
The server workslinear — labour does not accelerate 1500ms
Response travelseased 1100ms
  1. Travel eases. Work is linear. An eased arc reads as something moving; labour has no acceleration.
  2. Nothing animates that is not happening. No decorative pulses, no idle drift.
  3. Reduced motion renders the final state. Not a faster animation — none.
  4. Time is pausable, and the pause is offered. Elapsed time accumulates only while running, so a pause freezes the exact instant.

The way in

The word is the door.

  1. Captions are clicked, not marks. A circle that is also a button stops being a symbol and becomes a control.
  2. A door looks like a link — accent colour, dotted underline. No invented affordance.
  3. Every mark has a door. “Some are clickable” must be discovered; “every one is” can be guessed.
  4. Opening a door stops time, and closing it resumes the same instant.

Shape carries kind, colour carries state, position carries time, size carries quantity — after Bertin. The grammar-first approach is borrowed from Isotype and Aicher's 1972 system, whose own documentation calls its rules “comparable with the rules of grammar for a language”.
